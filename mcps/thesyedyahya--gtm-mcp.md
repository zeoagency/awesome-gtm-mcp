# thesyedyahya/gtm-mcp

[Catalog](../README.md) · [Tool index](../TOOL_INDEX.md) · [Upstream project](https://github.com/thesyedyahya/gtm-mcp) · [Machine-readable inventory](../data/mcps/thesyedyahya--gtm-mcp.json)

**26 extracted tools.** Summarize container resources, find tags by type or variable reference, and optionally edit draft tags.

Snapshot: 2026-10-13 · [08a6bf3e4d8d](https://github.com/thesyedyahya/gtm-mcp/tree/08a6bf3e4d8d71899ec07ba1ac42462290546e7c) · Method: mixed.

Exposure: All 26 tools are registered unconditionally; four write handlers are gated by GTM_ALLOW_WRITES, false by default. Account, container, and workspace defaults come from environment.

## Limits

- Offline tools/list was generated by executing only the original decorated function definitions with installed MCP/Pydantic; dependency ranges are not locked upstream, so SDK-version-dependent schema details can vary. No GTM handler or authentication was executed.
- The shared _resolve_path helper appends configured container/workspace defaults even for account/container operations; setting defaults can produce invalid account or container API paths. Missing IDs without matching defaults also produce incomplete paths.
- List operations do not follow nextPageToken, so accounts, containers, workspaces, entities, permissions, and audit results can be incomplete.
- list_user_permissions uses only readonly scope unless writes are enabled; manage.users scope is included solely in the write-enabled scope set.
- list_versions describes published versions but lists version headers without publication filtering; create_version_and_publish does not inspect compilerError before publishing.
